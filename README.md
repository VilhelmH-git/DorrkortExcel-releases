# DorrkortExcel-releases

Signed DorrkortExcel releases - the in-app update channel. Mirrored by packaging/new_release.ps1 in the main repo.

To install: download the newest `DorrkortExcel-<version>-sidladdning.zip` under Releases, unpack the WHOLE zip and double-click `Install.cmd`. Or install it from BoomerHubb.
